# Security

This repository holds my GitHub profile README and the workflows that keep it current. There is no
service here and no user data.

## Reporting a vulnerability

Email **pablogalerani@gmail.com** rather than opening a public issue.

The plausible issues in a repository like this one:

- a workflow with an injectable input, an over-scoped token, or a step that could be made to run
  attacker-controlled code
- a third-party badge or image endpoint being used to track visitors to my profile, or one that
  has been taken over since I linked it
- a link that no longer points where it claims to
- **anything on the profile that discloses information about a bug bounty target** — a sector,
  a date, an amount, or a description narrow enough to identify one company

That last one is the most serious bug this repository can have. Several of my reports are still
open, and a profile README is the last place anyone looks for a leak. If you spot one, email me
rather than filing an issue, since an issue describing the leak republishes it.
